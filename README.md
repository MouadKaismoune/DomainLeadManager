# Domain Lead Manager

نسخة أولى بسيطة لتجميع النطاقات والشركات وربطها بفرص بيع محتملة.

تستخدم الواجهة PySide6. ثبّت الاعتماديات عبر:

```bash
python3 -m pip install -r requirements.txt
```

## التشغيل

من جذر المشروع:

```bash
python3 main.py
```

تُنشأ قاعدة البيانات المحلية تلقائيًا في `data/app.db` من ملف `schema.sql`.

## الاختبارات

```bash
python3 -m unittest discover -s tests
```

في مساحة العمل، تتم إضافة الشركة والجهة المسؤولة والبريد والملاحظات إلى الدومين المحدد فقط.
يمكن إعادة استخدام نفس الشركة في دومين آخر، مع بقاء كل علاقة Lead وملاحظاتها منفصلة.
